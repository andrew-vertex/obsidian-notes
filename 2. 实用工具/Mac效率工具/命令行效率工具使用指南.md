# 命令行效率工具使用指南

> 适用场景：在 macOS 终端中更快地浏览文件、搜索内容、跳转目录和按代码结构进行重构。

## 笔记概览

### 整体结构

本文按「内容搜索 → 查看 → 文件查找 → 选择 → 导航 → 结构化改写」的日常工作流介绍 8 个已安装工具。每个工具独立成节，并提供可直接复制的命令速查表。

### 各节内容概要

| 章节/部分 | 核心内容 | 关键点 |
|---|---|---|
| 工具定位 | 将传统终端需求映射到合适工具 | 先选工具，再记命令 |
| ripgrep | 高速全文和正则搜索 | 搜内容用 `rg`，搜文件名用 `fd` |
| bat | 带高亮的文件阅读 | 替代多数交互式 `cat` 场景 |
| fd | 按名称查找文件 | 默认尊重 `.gitignore` |
| fzf | 交互式模糊选择 | 可与 `fd`、Git、shell 历史组合 |
| eza / tree | 浏览或导出目录层级 | 前者适合日常浏览，后者适合稳定输出 |
| zoxide | 基于访问历史跳转目录 | 初始化后用 `z` 替代大多数 `cd` |
| coreutils | GNU 基础工具补充 | macOS 默认以 `g` 前缀安装 |
| ast-grep | 基于语法树搜索和重写 | 不易受空格、换行影响 |
| 组合工作流 | 将工具串联完成任务 | `fd + fzf + bat` 是高频组合 |

### 笔记特征

- 每个工具都有独立的命令表：命令、作用和可运行示例。
- 示例以 macOS、zsh、Homebrew 的本地环境为准。
- 重点标注 `rg`/`fd` 的搜索边界、`zoxide` 初始化要求，以及 GNU 工具的 `g` 前缀。
- 覆盖文件定位、预览、打开和结构化代码搜索等高频研发操作。

## 工具定位

| 传统需求 | 推荐工具 | 为什么 |
|---|---|---|
| 搜索文件内容 | `ripgrep`（`rg`） | 速度快、支持正则，默认尊重 `.gitignore`。 |
| 阅读源码或配置 | `bat` | 有行号、语法高亮和分页。 |
| 按文件名找文件 | `fd` | 语法简洁、速度快，默认尊重 `.gitignore`。 |
| 从很多候选项中选择 | `fzf` | 实时模糊匹配，键盘操作完成筛选。 |
| 浏览当前目录 | `eza` | 显示 Git 状态、文件类型和目录树。 |
| 展示/输出目录结构 | `tree` | 结果稳定，适合文档和排查。 |
| 回到常用项目目录 | `zoxide` | 根据访问频率和最近使用记录排序。 |
| 使用 GNU 风格基础命令 | `coreutils` | 补齐或增强 macOS 自带 BSD 命令。 |
| 找或改特定代码形态 | `ast-grep`（`sg`） | 依据语法树匹配，不会被空格和换行轻易干扰。 |

## ripgrep：高速全文搜索

`ripgrep` 的命令是 `rg`，用于在文件**内容**中进行快速的文本或正则表达式搜索。它默认遵循 `.gitignore`、跳过隐藏文件和二进制文件；这与按文件名查找的 `fd` 互补。

| 命令 | 作用 | 示例 |
|---|---|---|
| `rg 关键词` | 在当前目录递归搜索内容 | `rg 'TODO'` |
| `rg -n 关键词` | 显示匹配行号 | `rg -n 'CaseService' Hyperion/src` |
| `rg -i 关键词` | 忽略大小写 | `rg -i 'exception'` |
| `rg -F 文本` | 按普通文本匹配，不把特殊字符当正则 | `rg -F 'a.b[c]'` |
| `rg -t 类型 关键词` | 只搜索某类文件 | `rg -t java 'needManual'` |
| `rg -g 模式 关键词` | 用 glob 限定或排除路径 | `rg -g '*.md' -g '!Archive/**' 'Obsidian'` |
| `rg -l 关键词` | 仅输出命中的文件名 | `rg -l 'TODO'` |
| `rg -c 关键词` | 输出每个文件的匹配数量 | `rg -c 'import ' Hyperion/src` |
| `rg --files` | 列出可搜索的文件 | `rg --files -g '*.java'` |
| `rg -uuu 关键词` | 搜索被忽略、隐藏和二进制文件 | `rg -uuu 'secret'` |

> [!warning] `-uuu` 会绕过 `.gitignore` 并搜索隐藏文件，可能扫描 `node_modules`、构建产物或包含敏感配置的 `.env` 文件；日常优先使用默认行为，必要时用 `-g` 精确放开范围。

**高频判断：**找“内容出现在哪里”用 `rg`；找“文件叫什么”用 `fd`；找“代码语法形态”用 `sg`。

## bat：更适合阅读的 cat

`bat` 适合快速查看源码、JSON、YAML 和日志片段；输出到管道时会自动退化为适合机器处理的纯文本。

| 命令 | 作用 | 示例 |
|---|---|---|
| `bat 文件` | 带高亮、行号和分页查看文件 | `bat package.json` |
| `bat -n 文件` | 始终显示行号 | `bat -n .zshrc` |
| `bat -l 类型 文件` | 强制指定语法类型 | `bat -l json response.txt` |
| `bat -p 文件` | 不分页、不显示装饰，适合短内容 | `bat -p README.md` |
| `bat --diff 文件` | 与 Git 索引中的版本对比显示 | `bat --diff src/app.ts` |
| `bat --list-languages` | 查看可用语法类型 | `bat --list-languages` |

> [!tip] 可以在 `~/.zshrc` 中设置 `alias cat='bat'`；但脚本中仍建议使用原生 `cat`，以免颜色和分页影响输出。

## fd：更快的文件查找

`fd` 按名称（正则表达式）查找文件，默认忽略隐藏文件、`.gitignore` 忽略项和 `.git` 目录。

| 命令 | 作用 | 示例 |
|---|---|---|
| `fd 模式` | 当前目录递归找名称匹配项 | `fd 'service'` |
| `fd 模式 路径` | 限定搜索根目录 | `fd '\\.java$' src` |
| `fd -e 扩展名` | 按扩展名筛选 | `fd -e md` |
| `fd -t f` / `fd -t d` | 仅文件 / 仅目录 | `fd -t d 'spec'` |
| `fd -H` | 包含隐藏文件 | `fd -H '.env'` |
| `fd -I` | 不遵循 `.gitignore` | `fd -I node_modules` |
| `fd -x 命令` | 对每个结果执行命令 | `fd -e java -x wc -l {}` |
| `fd -X 命令` | 将全部结果一次传给命令 | `fd -e java -X wc -l` |

> [!warning] `fd` 匹配的是**路径名**，不是文件内容；搜索内容请用 `rg`。`-x` 中 `{}` 代表完整路径。

## fzf：交互式模糊选择

`fzf` 从标准输入读取候选项，打开可搜索的交互式选择界面；按 Enter 输出选中项，按 Esc 取消。

| 命令 | 作用 | 示例 |
|---|---|---|
| `fzf` | 从标准输入筛选 | `printf '%s\\n' api web worker \| fzf` |
| `fd \| fzf` | 从文件列表中选一个文件 | `fd -t f \| fzf` |
| `fzf --multi` | 允许 Tab 多选 | `fd -e md \| fzf --multi` |
| `fzf --preview 'bat …'` | 选择时预览文件内容 | `fd -t f \| fzf --preview 'bat --color=always {}'` |
| `Ctrl-R` | 搜索 zsh 历史命令（完成 shell 集成后） | 在终端直接按 `Ctrl-R` |
| `Ctrl-T` | 把选择的文件插入当前命令行（完成 shell 集成后） | 输入 `code ` 后按 `Ctrl-T` |

一次性初始化：

```zsh
source <(fzf --zsh)
```

## eza：增强版 ls

`eza` 用于日常目录浏览，能显示文件类型、大小、修改时间及 Git 状态；它适合交互查看，不适合依赖固定格式的脚本解析。

| 命令 | 作用 | 示例 |
|---|---|---|
| `eza` | 列出当前目录 | `eza` |
| `eza -l` | 长格式列表 | `eza -l` |
| `eza -la` | 长格式并显示隐藏文件 | `eza -la` |
| `eza -T` | 树形展示目录 | `eza -T -L 2` |
| `eza --git` | 附带 Git 状态列 | `eza -la --git` |
| `eza -lh --sort=modified` | 人类可读大小，按修改时间排序 | `eza -lh --sort=modified` |
| `eza -l --group-directories-first` | 目录排在文件前 | `eza -l --group-directories-first` |

## tree：目录树展示

`tree` 以稳定的纯文本树展示层级，适合在 README、排障记录或设计文档中粘贴目录结构。

| 命令 | 作用 | 示例 |
|---|---|---|
| `tree` | 展示当前目录树 | `tree` |
| `tree -L 深度` | 限制最大层级 | `tree -L 2` |
| `tree -a` | 包含隐藏文件 | `tree -a -L 2` |
| `tree -d` | 仅显示目录 | `tree -d -L 3` |
| `tree -I 模式` | 排除名称匹配项 | `tree -I 'node_modules\|.git\|target' -L 3` |
| `tree -h` | 显示文件大小 | `tree -h -L 2` |

## zoxide：智能目录跳转

`zoxide` 会记录进入过的目录，并按照访问频率与最近使用情况排序。初始化后，用 `z` 进行模糊跳转，用 `zi` 通过 `fzf` 交互选择。

| 命令 | 作用 | 示例 |
|---|---|---|
| `eval "$(zoxide init zsh)"` | 在当前 shell 启用 `z`、`zi` | 写入 `~/.zshrc` 后重开终端 |
| `z 关键词` | 跳到最匹配的已访问目录 | `z hyperion` |
| `z 词1 词2` | 用多个词缩小匹配范围 | `z yibao hyperion` |
| `zi 关键词` | 通过 fzf 交互选择目录 | `zi projects` |
| `zoxide query 关键词` | 只输出最佳路径，不切换目录 | `zoxide query hyperion` |
| `zoxide remove 路径` | 删除失效目录记录 | `zoxide remove ~/old-project` |

> [!warning] `zoxide` 只会跳转到你曾经 `cd` 进入过（或已显式添加）的目录。刚安装没有历史记录是正常的。

## coreutils：GNU 基础工具集

Homebrew 的 `coreutils` 提供 GNU 版本的基础命令。在 macOS 上，Homebrew 默认以 `g` 前缀安装它们，避免替换系统自带的 BSD 命令。

| 命令 | 作用 | 示例 |
|---|---|---|
| `gdate` | GNU `date`；支持丰富的日期计算 | `gdate -d 'next monday' '+%F'` |
| `greadlink` | GNU `readlink`；`-f` 解析绝对真实路径 | `greadlink -f ./link-or-path` |
| `gtimeout` | 为命令设置最长执行时间 | `gtimeout 10 curl https://example.com` |
| `gsha256sum` | 计算或校验 SHA-256 摘要 | `gsha256sum archive.tar.gz` |
| `gcp` | GNU `cp` | `gcp --reflink=auto source target` |
| `gsort` | GNU `sort` | `gsort -h sizes.txt` |

若确实要优先使用 GNU 命令，可将其目录加入 PATH（会影响所有终端命令行为）：

```zsh
export PATH="$(brew --prefix coreutils)/libexec/gnubin:$PATH"
```

## ast-grep：按代码结构搜索与改写

`ast-grep` 的命令是 `sg`。它先按编程语言解析源码，再匹配 AST，因此即使换行或调整空格，代码形态仍可匹配；适合代码审查、迁移和批量重构。

| 命令 | 作用 | 示例 |
|---|---|---|
| `sg --pattern '模式'` | 在当前目录按代码结构搜索 | `sg --pattern 'console.log($$$)'` |
| `sg --lang 语言 --pattern '模式'` | 显式指定语言 | `sg --lang java --pattern 'logger.info($ARG)'` |
| `sg --pattern '模式' 路径` | 在指定目录搜索 | `sg --lang java --pattern 'Objects.requireNonNull($ARG)' Hyperion/src` |
| `sg --rewrite '新形式' --pattern '旧形式'` | 预览替换后的结果 | `sg --lang js --pattern 'var $A = $B' --rewrite 'let $A = $B'` |
| `sg scan` | 按项目规则扫描 | `sg scan` |
| `sg new 规则名` | 生成自定义规则骨架 | `sg new no-console-log` |

变量规则：`$NAME` 匹配一个 AST 节点，`$$$ARGS` 匹配零个或多个节点。例如 `foo($$$ARGS)` 可以匹配任意参数个数的 `foo(...)` 调用。

> [!warning] 批量改写前先运行搜索或 `--rewrite` 预览，并限定 `--lang` 与目录。不同版本的 `sg` 写回选项可能不同，请先用 `sg --help` 确认。

## 组合工作流

| 目标 | 命令 | 说明 |
|---|---|---|
| 在源码中找关键词并交互预览 | `rg -l '关键词' \| fzf --preview 'bat --color=always {}'` | `rg` 筛出内容命中的文件，`fzf` 选择，`bat` 预览。 |
| 找文件、预览、用 VS Code 打开 | `code "$(fd -t f \| fzf --preview 'bat --color=always {}')"` | `fd` 提供候选，`fzf` 筛选，`bat` 预览。 |
| 快速浏览近期修改文件 | `eza -la --git --sort=modified` | 适合在项目根目录查看工作区。 |
| 查看干净的项目目录树 | `tree -I 'node_modules\|.git\|target\|dist' -L 3` | 可直接粘贴到文档或 Issue。 |
| 查找 Java 文件并批量统计 | `fd -e java -X wc -l` | `-X` 仅执行一次，避免多次启动 `wc`。 |
| 在常用项目间跳转 | `z hyperion` / `zi yibao` | 先用 `z`，不确定候选时用 `zi`。 |
| 找出特定调用形态 | `sg --lang java --pattern 'Objects.requireNonNull($ARG)' Hyperion/src` | 用代码结构而不是普通字符串匹配。 |

## 最佳实践

1. 日常阅读优先用 `bat`，脚本和机器处理仍使用稳定输出的原生 `cat`、`sed` 等工具。
2. 先区分三种搜索：内容搜索用 `rg`，文件名搜索用 `fd`，代码结构搜索用 `sg`。
3. 先记住 `rg -t`、`rg -g`、`rg -l` 与 `fd -e`、`fd -t`、`fd -H`、`fd -I`，即可覆盖绝大多数搜索需求。
4. 将 `fzf` shell 集成和 `zoxide init zsh` 写入 `~/.zshrc`，让 `Ctrl-R`、`Ctrl-T`、`z` 成为肌肉记忆。
5. 用 `ast-grep` 批量重构时，先缩小语言和路径范围，再在 Git diff 中审查结果。
