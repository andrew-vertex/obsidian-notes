# 企业知识库问答项目

> 项目状态：待启动。先验证 RAG，不引入开放式多工具 Agent。

[TOC]

## 项目目标

- 对私有文档提供有证据引用的问答。
- 支持文档增量更新、租户/ACL 过滤和错误分析。
- 建立可重复的检索与生成评测。

## 最小范围

- Java 服务端 + 一个 LLM + 一个 Embedding 模型。
- 文档解析、切分、索引、Hybrid Search、Rerank、答案引用。
- 50～200 条 Golden Set、Trace 和基础成本看板。

## 验收指标

| 维度 | 指标 | 目标值 |
| --- | --- | --- |
| 检索 | Hit Rate@K / MRR | 待基线测试后填写 |
| 生成 | Faithfulness / Citation Accuracy | 待基线测试后填写 |
| 性能 | TTFT / P95 延迟 | 待容量目标确认 |
| 安全 | ACL 越权用例通过率 | 100% |
