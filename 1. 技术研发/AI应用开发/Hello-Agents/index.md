## 课程目标

- 理解智能体、LLM 与 Agentic Workflow 的基础概念；
- 掌握 ReAct、Planning、Reflection、Memory、RAG 和协议等核心模块；
- 能够使用框架，也能理解框架内部的状态、工具与控制循环；
- 从 Demo 进一步关注评估、安全、可观测性和生产工程边界。

## 学习原则

1. 每章笔记优先记录“概念边界、机制、实践和踩坑”，不复刻课程原文。
2. 实践代码必须补充输入校验、异常处理、权限边界和验证方法。
3. 时效性较强的模型、框架和协议内容需标注验证日期。
4. 学完一章后更新本页状态，并将新建笔记链接到对应章节。
