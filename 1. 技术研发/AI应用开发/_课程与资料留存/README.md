# 外部课程与参考资料留存说明

本目录为 AI 应用开发学习过程中引入的**外部体系、开源教程、面试专题与半拉子课程的【冷冻留存区】**。

## 留存原则

1. **零删减留存**：所有课程的原始内容、大纲与历史进度 100% 完整保留，不作破坏性删除。
2. **解耦心智**：外部教程通常按各自作者的章节大纲铺设（容易形成很多完成度 <10% 的空架子）。将其归拢至此后，主知识库即可摆脱“多套教程体系互相打架”的认知负担。
3. **按需回捞**：当你在主干目录（`01~05 领域主干`）深入学习或编写某项技术时，可随时全局搜索本目录，将有价值的片段或代码片段顺手迁移进主干单篇笔记中。

- **`Hello-Agents/`**：Datawhale 开源智能体教程《Hello-Agents：从零开始构建智能体》学习笔记与索引。
- **`吴恩达-Agentic-AI/`**：吴恩达关于 Agentic AI 工作流课程的课堂记录（第 1~5 节）。
- **`AI 应用开发学习体系(JavaGuide).md`**：JavaGuide AI 专题的原始粗粒度学习地图。
