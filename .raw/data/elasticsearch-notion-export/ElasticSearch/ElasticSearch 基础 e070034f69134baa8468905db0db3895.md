# ElasticSearch 基础

- ElasticSearch 简介
    - 非结构化数据
        - 结构化数据：遵循特定格式或模型的数据，这种数据通常存储在关系型数据库中，具有预定义的结构和字段，适合标准化和高效的数据管理操作。
        - 非结构化数据：不遵循特定格式或模式的数据，这种数据通常存储在非关系型数据中，没有预定义的结构和字段，适合内容管理，文本挖掘等场景。
        
        [**Elasticsearch 为何被称为“非结构化数据库”**](ElasticSearch%20%E5%9F%BA%E7%A1%80/Elasticsearch%20%E4%B8%BA%E4%BD%95%E8%A2%AB%E7%A7%B0%E4%B8%BA%E2%80%9C%E9%9D%9E%E7%BB%93%E6%9E%84%E5%8C%96%E6%95%B0%E6%8D%AE%E5%BA%93%E2%80%9D%202dfd60c9df5180a19ef6fced6f0fe189.md)
        
    - 全文检索引擎
        
        > 全文检索引擎是一种用于在大量文本数据中快速查找并返回包含特定关键词或短语的文档或文本片段的工具。它的核心功能包含数据索引和数据检索，从而实现高效的搜索体验。
        > 
        - 全文检索引擎的工作流程
            - 数据采集和存储：将原始文档数据导入系统中并存储
            - 分词和索引：将文档内容进行分词，建立倒排索引
            - 索引存储：将建立的索引结构存储在全文检索系统中
            - 处理查询：解析查询参数，利用倒排索引快速查找匹配的文档
            - 匹配和排序：对匹配的文档进行相关性算法的排序，将最相关的结果优先返回
        - 全文检索引擎的应用场景
            
            全文检索引擎被广泛应用于需要处理和查询大量文本数据的场景，包括网页内容搜索、电子商品搜索、文献管理等。
            
    - ElasticSearch 简介
        
        > ElasticSearch 是一个开源的分布式全文搜索和分析引擎，它能够实时地存储、搜索和分析海量数据。
        > 
        > 
        > ElasticSearch 通常与 Logstash（数据收集和处理）和 Kibana（数据可视化）组合使用，组成 Elastic Stack（简称 ELK Stack），提供一体化的数据管理和分析解决方案，被广泛应用于日志数据分析、实时监控等领域，其中 ElasticSearch 负责数据的存储、搜索和分析。
        >

    - ElasticSearch 搜索原理
        
        ElasticSearch 将文档数据拆分为更小的单位（通常是单词或词组），然后创建倒排索引并存储，查询时根据倒排索引检索数据，实现数据的高效查询。分词是建立索引的基础步骤，倒排索引是全文检索引擎的核心结构，它记录了词和出现该词的文档之间的关系。通过倒排索引，可以快速定位包含某个词的所有文档，从而大幅提高查询效率。
        
        - 分词 - Tokenization
            
            分词就是将文档分解为独立的单词和词组的过程，分词的任务由分词器（analyzer）负责执行
            
        - 倒排索引 - Inverted Index
            - 正向索引：基于文档 ID 映射文档，查询特定词条需要遍历所有文档，判断每个文档是否包含指定词条
                
                ![Untitled](ElasticSearch%20%E5%9F%BA%E7%A1%80/Untitled%201.png)
                
            - 倒排索引：对文档内容进行分词，对词条创建索引实现词条和包含这些词条的文档及其位置的映射，每个词对应一个列表，包含所有包含该词的文档 ID 和词在文档中的位置。
                
                ![Untitled](ElasticSearch%20%E5%9F%BA%E7%A1%80/Untitled%202.png)
                
            
            倒排索引相较于正向索引更适合于快速查找包含特定词的文档，构建较为复杂，但是提供了高效的搜索性能。
            
    - ElasticSearch 特点
        - 分布式架构：ElasticSearch 支持分布式，支持大规模数据和高并发查询，支持水平扩展
        - 全文搜索：ElasticSearch 将文档数据分词和建立倒排索引，提高存储和检索效率；同时支持多种查询类型，实现复杂的查询选项
        - 实时搜索：ElasticSearch 支持近实时搜索，即数据在写入后几乎可以立即被搜索
        - 聚合分析：ElasticSearch 提供强大的数据分析和统计聚合功能
- ElasticSearch 核心概念
    - ElasticSearch 核心概念
        
        > ElasticSearch 是 NoSQL （No Only SQL）非关系型数据库，它有很多概念和 MySQL 相似。
        > 
        - 结构概念 - 构成了数据存储、组织和查询方式
            
            > 注意：在 Elasticsearch 6.x 及之前的版本中，Type 类型用于在一个 Index 索引中区分不同类型的文档的逻辑分区。但从 7.0 版本开始，为了简化数据模型，Type类型概念已经被弃用，不推荐使用，即 7.0 版本开始，每个 Index 索引只能有一个类型 ‘_doc’
            > 
            - Index 索引：索引是存储一组相同类型文档的集合，类似于关系型数据库的表。它是存储和管理文档的基础单元，索引名称不能重复。一个索引中可以包含多个文档。
            - Document 文档：文档是 ElasticSearch 存储的基本数据单元，ElasticSearch 是面向文档存储的（数据会被序列化为 JSON 对象存储在 ElasticSearch 中），每个文档是一个JSON对象，包含特定的数据字段及值。类似于关系数据库中的一行记录。
            - Field 字段：字段是文档的属性和键值对，类似于关系数据库中的列。每个字段都有一对名称和值。
            - Mapping 映射：映射定义了索引的文档结构和字段类型。类似于关系型数据库中的模式定义，定义字段的名称、字段的数据类型和其他属性。Mapping 映射将决定字段如何被索引和存储。
            - DSL（Domain Specific Language）是 ElasticSearch 提供的基于 JSON 格式的请求语句，用于定义 ElasticSearch 的搜索请求。类似于关系型数据库的 SQL（用于管理和操作关系型数据库的标准语言）。DSL 语句更适用于全文搜索、负复分析；支持各种查询，包括布尔查询、嵌套查询、聚合查询等。
            - ElasticSearch VS MySQL
                
                
                | ElasticSearch  | MySQL | 说明 |
                | --- | --- | --- |
                | Index 索引 | Table 表 | 索引是存储文档的集合 |
                | Document 文档 | Row 行 | 文档是存储的基本数据单元，格式为JSON，可以包含多个字段 |
                | Field 字段 | Column 列 | 字段是文档的属性和值 |
                | Mapping 映射 | Schema 表结构 | 映射是定义文档的文档结构和字段类型，决定数据如何被索引和存储 |
                | DSL  | SQL | DSL是基于 JSON 格式的请求语句，用于复杂搜索和分析 |
                
                MySQL 和 ElasticSearch 的使用场景不同
                
                - MySQL：MySQL 支持事务，适用于可靠性、完整性和一致性要求较高的场景。
                - ElasticSearch：ElasticSearch 是分布式搜索和分析引擎，适用于海量数据搜索、实时分析和统计等场景。
                
                ![Untitled](ElasticSearch%20%E5%9F%BA%E7%A1%80/Untitled%203.png)
                
        - 分布式概念 - 实现分布式数据存储和检索
            - Node 节点：ElasticSearch集群中的单个实例，对应一个ElasticSearch进程。
            - Cluster 集群：一个或多个ElasticSearch节点组成的集群，协同工作以提供索引和搜索功能。集群通过分片和副本机制实现高可用，集群提供负载均衡的能力，在多个节点间均匀分布数据和请求；同时集群具有动态添加或移除节点以调整集群的容量和性能的能力。
            - Shard 分片：ElasticSearch将数据水平拆分为多个部分进行分片存储，实现水平分割扩展和负载均衡，一个索引可以包含多个分片。
            - Replica 副本：Shard 分片分为 Primary Shard（主分片）和 Replica Shard（副本分片）。主分片用于处理读写请求并将数据复制到副本分片中；副本分片作为主分片的副本，提供数据冗余的能力，用于响应读请求，提高查询性能的同时，提高系统的可用性和故障恢复的能力。

- ElasticSearch 分词器
    
    ElasticSearch 通过分词器进行分词，默认的分词器为 standard 分词器，该分词器在处理中文时效果不佳，无法正确识别和分割中文词汇。IKAnalyzer 分词器提供了对中文的专业分词支持，同时提供了多种分词模式（如最细粒度 - ik_max_word，最少切分 - ik_smart）。
    
    > IKAnalyzer 是一个开源的中文分词器，用于对中文文本的分词和检索。
    > 
    - 测试 IKAnalyzer

    - 使用 IKAnalyzer
        
        在参加索引时，可以在字段映射中指定使用 IKAnalyzer 
        
        ```bash
        PUT /my_index
        {
            "mappings": {
                "properties": {
                    "content": {
                        "type": "text",
                        "analyzer": "ik_max_word", # 创建索引时使用 ik_max_word 作为分词器，将文本拆分为细粒度的词
                        "search_analyzer": "ik_smart" # 搜索时使用 ik_smart，将句子拆分为较粗粒度的词，提高搜索的效率
                    }
                }
            }
        }
        ```
        
        插入文档 
        
        ```bash
        POST /my_index/_doc/1
        {
            "content": "中华人民共和国成立了"
        }
        ```
        
        查询文档：使用 Match Query 进行全文搜索（它会对搜索参数进行分词，用于全文搜索。另一种搜索方式为 Term Query，它是精确匹配查询，不会对查询参数进行分词，而是将其作为一个整体进行搜索，用于需要精确匹配的chang jing）
        
        ```bash
        GET /my_index/_search
        {
          "query": {
            "match": {
              "content": "中华"
            }
          }
        }
        ```
        
    - IKAnalyzer 两种分词模式
        - ik_max_word - 最细粒度（最大词数模式）：它会尽可能多地将文本拆分为所有可能的词语，分词的粒度细，分词结果包括所有的可能的子词；适用于需要全面、高召回率的搜索场景，例如 全文检索、内容推荐、文本分析 等场景。
        - ik_smart - 最少切分（智能分词模式）：将文本切分成较为粗粒度的词汇，减少分词的数量；适用于对搜索效率要求较高的场景，例如常规搜索、分类、过滤等场景。
    - IKAnalyzer 自定义词典
        
        IKAnalyzer 支持自定义词典，可以在指定的分词器下的 config（`/mydata/elasticsearch/plugins/analysis-ik/config`） 目录中的 `IKAnalyzer.cfg.xml` 文件中配置自定义词典路径，可以拓展和停用词库，从而进一步优化 IKAnalyzer 的分词效果和性能。
        
        - 拓展词库和停用词库
            
            > 添加 ext.dic 和 stopword.dic 文件，在其中分别保存扩展词库和禁用词库，在配置文件中配置扩展字典和禁用字典的位置
            > 
            
            ```bash
            cat > ext.dic <<- EOF
            奥利给
            EOF
            ```
            
            ```bash
            cat > stopword.dic <<- EOF
            你好
            EOF
            ```
            
            ```xml
            <?xml version="1.0" encoding="UTF-8"?>
            <!DOCTYPE properties SYSTEM "http://java.sun.com/dtd/properties.dtd">
            <properties>
                    <comment>IK Analyzer 扩展配置</comment>
                    <!--用户可以在这里配置自己的扩展字典 -->
                    <entry key="ext_dict">ext.dic</entry>
                     <!--用户可以在这里配置自己的扩展停止词字典-->
                    <entry key="ext_stopwords">stopword.dic</entry>
            </properties>
            ```

- ElasticSearch 使用
    
    ElasticSearch 通过 RESTful API 进行交互
    
    - ElasticSearch 索引操作
        - 索引基础操作
            - 新增索引
                
                ```bash
                PUT /my_index
                ```
                
                ```json
                PUT /my_index
                {
                    "mappings": {
                        "properties": {
                            "new_field": {
                                "type": "text"
                            }
                        }
                    }
                }
                ```
                
                返回结果如下
                
                ```json
                {
                    "acknowledged": true, # 主节点已经确认索引创建成功
                    "shards_acknowledged": true, # 集群中的所有节点已经确认分片索引创建成功
                    "index": "my_index" # 索引名称
                }
                ```
                
            - 查询索引
                
                ```bash
                GET /my_index
                ```
                
                返回结果如下
                
                ```json
                {
                    "my_index": {
                        "aliases": {}, # 别名
                        "mappings": {},# 映射
                        "settings": {  # 设置
                            "index": { # 索引内容
                                "routing": {
                                    "allocation": {
                                        "include": {
                                            "_tier_preference": "data_content"
                                        }
                                    }
                                },
                                "number_of_shards": "1",   # 分片数量
                                "provided_name": "test",
                                "creation_date": "1718239543045",
                                "number_of_replicas": "1", # 副本数量
                                "uuid": "ALwRUM26TgCfBZy_hiEEKA",
                                "version": {
                                    "created": "7170399"
                                }
                            }
                        }
                    }
                }
                ```
                
            - 删除索引
                
                ```bash
                DELETE /my_index
                ```
                
                返回结果如下
                
                ```json
                {
                    "acknowledged": true
                }
                ```
                
            - 查询所有索引元数据
                
                ```bash
                GET /_all
                ```
                
            - 查询索引摘要信息
                
                ```bash
                GET /_cat/indices?v
                ```
                
                返回结果如下
                
                ```bash
                health status index                           uuid                   pri rep docs.count docs.deleted store.size pri.store.size
                ```

        - 索引Mapping操作
            - Mapping属性
                
                Mapping 映射定义了索引的文档结构和字段类型，它对索引中的文档的约束。
                
                映射可以指定字段的数据结构、索引选项、格式化规则、分词器等。通过映射属性详细控制字段的行为和存储方式，满足不同的搜索和分析需求。
                
                - type - 常见数据结构
                    - 文本类型
                        - text：支持分词的全文搜索字段（**分词匹配**的字段）。不用于排序和聚合。
                        - keyword：**精确匹配**的字段；通常用于过滤、排序和聚合。
                    - 数值类型
                        - byte：有符号的8位整数
                        - integer：32 位整数
                        - long：64 位整数
                        - short：16 位整数
                        - byte：8 位整数
                        - float：32 位浮点数
                        - double：64 位浮点数
                    - 布尔类型
                        - boolean：布尔值
                    - 日期类型
                        - date：日期字段（可以指定日期格式）
                        
                        ```json
                        {
                            "properties": {
                                "birthday": {
                                    "type": "date",
                                    "format": "yyyy‐MM‐dd HH:mm:ss||yyyy‐MM‐dd||epoch_millis", // 设置日期的格式
                                    "ignore_malformed": false, // 是否忽略格式错误，默认值为false，当字段值不符合指定格式时，则会抛出错误并拒绝索引该文档
                                    "null_value": 1970-01-01"  // 空值的默认值 
                                }
                            }
                        }
                        ```
                        
                    - 范围类型
                        - integer_range：整数范围
                        - long_range：长整数范围
                        - float_range：浮点数范围
                        - double_range：双精度范围
                        - date_range：日期范围
                        
                        ```json
                        // mapping 设置
                        PUT /my_index
                        {
                            "mappings": {
                                "properties": {
                                    "salary": {
                                        "type": "integer_range"
                                    }
                                }
                            }
                        }
                        // 加入数据
                        POST /my_index/_doc/1
                        {
                          "salary": {
                            "gte": 3000,
                            "lte": 5000
                          }
                        }
                        // gte lte 大于等于 小于等于
                        // gt lt  大于 小于
                        // 也可以以数组的形式加入文档，达到多区间匹配
                        POST /my_index/_doc/2
                        {
                            "salary": [
                                {
                                    "gte": 1000,
                                    "lte": 2000
                                },
                                {
                                    "gte": 3000,
                                    "lte": 4000
                                }
                            ]
                        }
                        // 查询格式
                        GET /my_index/_search
                        {
                          "query": {
                            "range": {
                              "salary": {
                                "gte": 3000,
                                "lte": 5000
                              }
                            }
                          }
                        }
                        ```
                        
                    - 复杂类型
                        - object：嵌套对象
                        - nested：嵌套文档，用于高性能的嵌套对象查询
                            
                            ```json
                            "name": {
                                "type": "nested",
                                "properties": {
                                    "firstname": {
                                        "type": "keyword"
                                    },
                                    "lastname": {
                                        "type": "keyword"
                                    }
                                }
                            }
                            ```
                            
                    - 地理类型
                        - geo_point: 地理位置点（由经纬度确定的一个点）。
                            
                            用于存储单个地理位置即一个特定地点的坐标。
                            
                        - geo_shape: 地理形状（如多边形、线等 - 由多个 geo_point 组成的复杂几何图形）。
                            
                            geo_shape 由多个 geo_point 组成，geo_point 按特定顺序连接以形成完整的形状。
                            
                    - 二进制类型
                        - binary：存储 Base64 编码的二进制数据，即存储二进制数据经过Base64编码得到的字符串（不会对其进行索引，只能通过精确匹配搜索）
                    - 特殊类型
                        - ip：IPv4和IPv6的地址
                            
                            ```json
                            "ip_address": {
                            		"type": "ip"
                            }
                            ```
                            
                - index - 索引选项
                    
                    该字段是否创建索引，默认为 true
                    
                    ```json
                    "index": true
                    ```
                    
                - analyzer - 分词器
                    
                    指定该字段的分词器，适用于 text 类型，默认为 standard 分词器
                    
                    ```json
                    "analyzer": "standard"
                    ```
                    
                - store - 单独存储选项
                    
                    该字段是否单独存储，默认为 false
                    
                    ```json
                    "store": true
                    ```
                    
                - format - 日期格式
                    
                    日期格式，适用于 date 类型
                    
                    ```json
                    "format": "yyyy-MM-dd"
                    ```
                    
                - norms - 规范化选项
                    
                    该字段是否启用规范化，对于 text 类型字段通常禁用，默认为 true
                    
                    ```json
                    "norms": false
                    ```
                    
                - fields - 多字段定义
                    
                    多字段定义，允许同一个字段有多种索引方式，以满足不同的查询需求
                    
                    ```json
                    "name": {
                        "type": "text", # 用于分词全文搜索
                        "fields": {
                            "keyword": {
                                "type": "keyword", # 用于精确匹配，用于过滤、排序和聚合
                                "ignore_above": 256 # 如果字段长度超过256个字符，则该字段不是索引到精确匹配的keyword中（防止索引过长的字符串，从而节省存储空间和提升性能）
                            }
                        }
                    }
                    ```
                    
                - copy_to - 复制
                    
                    将当前字段的值复制到另一个字段，便于综合搜索，通常用于**多字段**综合搜索。
                    
                    ```json
                    "my_field": {
                      "type": "text",
                      "copy_to": "full_field"
                    }
                    ```
                    
                - null_value - 空值代替值
                    
                    指定字段的 `null` 值的替代值，适用于数值和日期类型
                    
                    ```json
                    "null_value": 0
                    ```
                    
                - boost - 权重
                    
                    字段权重，用于控制字段在搜索中的权重，默认值为 1.0 
                    
                    ```json
                    "boost": 2.0
                    ```
                    
                - properties - 子属性
                    
                    定义包含子属性的属性，用于定义复杂的嵌套结构，可以使用 `nested` 和 `object` 类型实现一个属性包含多个子属性（`nested` 和 `object` 类型相似，但 `nested` 类型允许在嵌套文档中进行独立的查询和过滤）
                    
                    ```json
                    "name": {
                        "type": "nested",
                        "properties": {
                            "firstname": {
                                "type": "keyword"
                            },
                            "lastname": {
                                "type": "keyword"
                            }
                        }
                    }
                    ```
                    
            - Mapping操作
                
                > ElasticSearch 只能创建和新增字段映射，不能直接修改或删除已有的字段映射，这是为了保证数据的完整性和避免潜在的混乱。
                > 
                - 创建Mapping属性
                    
                    PUT 创建索引时同时新增索引Mapping属性
                    
                    ```json
                    PUT /my_index
                    {
                        "mappings": {
                            "properties": {
                                "my_field": {
                                    "type": "text"
                                }
                            }
                        }
                    }
                    ```
                    
                - 新增Mapping属性
                    
                    使用 POST 和 PUT 都可以新增字段，如下新增一个新的字段 `my_field` 到已有的索引 **`my_index`** 中
                    
                    ```json
                    PUT /my_index
                    
                    PUT /my_index/_mapping
                    {
                      "properties": {
                        "my_field": {
                          "type": "text"
                        }
                      }
                    }
                    ```
                    
                - 获取已经的Mapping
                    
                    ```json
                    GET /my_index/_mapping
                    ```
                    
                - 对索引已经属性映射字段进行调整
                    
                    > 由于 ElasticSearch 不支持不能直接修改或删除已有的字段映射，因此不能通过命令直接调整原有的字段映射，只能新增。
                    > 
                    
                    通过创建新的索引并重建数据的方式进行索引属性字段映射的调整：
                    
                    - 原先索引和数据
                        
                        ```json
                        PUT /my_index
                        {
                          "mappings": {
                            "properties": {
                              "name": {
                                "type": "text"
                              },
                              "age": {
                                "type": "integer"
                              }
                            }
                          }
                        }
                        
                        POST /my_index/_doc/1
                        {
                          "name": "John Doe",
                          "age": 30
                        }
                        ```
                        
                    - 创建新的索引：创建一个新的索引 my_new_index，属性映射为调整后的所有属性 （这里将 `email` 的类型为 `keyword`，删除字段映射 `age` ）
                        
                        ```json
                        PUT /my_new_index
                        {
                          "mappings": {
                            "properties": {
                              "name": {
                                "type": "keyword"
                              }
                            }
                          }
                        }
                        ```
                        
                    - 重新索引数据：使用 `_reindex` API 将数据从旧索引中重新索引到新索引中
                        
                        ```json
                        POST /_reindex
                        {
                          "source": {
                            "index": "my_index"
                          },
                          "dest": {
                            "index": "my_new_index"
                          },
                           "script": {
                            "source": "ctx._source.remove('age')" // reindex 重新索引去除 age字段
                          }
                        }
                        ```
                        
                    - 删除旧索引：
                        
                        ```json

                        ```
                        
                    - 切换别名：将新索引的别名alisa设置为旧索引的名称
                        
                        ```json

                          "actions": [
                            {
                              "add": {
                                "index": "my_new_index",

                              }
                            }
                          ]
                        }
                        ```

        - 批量导入
            
            利用 bulk API 实现单个请求**批量执行多个文档操作**（如重建 - index、创建 - create、删除 - delete、更新 - update），这一功能常用于批量导入数据。
            
            bulk API 请求体内容是由一组或者多组的操作行（`action line`）和文档数据行（`data line`），每个操作行和数据行都是单独的 JSON 对象。
            
            ```json
            POST /_bulk
            { "index" : { "_index" : "my_index", "_id" : "1" } }
            { "my_field" : "value1" }
            { "index" : { "_index" : "my_index", "_id" : "2" } }
            { "my_field" : "value2" }
            ```
            
            - 操作行（`action line`）：定义执行的操作类型（如：index、create、update、delete）以及 目标索引和文档 ID
            - 文档数据行（`data line`）：包含实际的文档数据
            
            响应结果
            
            ```json
            {
              "took" : 4,       // 整个批量操作消耗的总时间（单位：毫秒）
              "errors" : false, // 导入过程是否产生错误
              "items" : [       // 批量操作中的每组操作执行的结果列表
                {
                  "index" : {
                    "_index" : "my_index",
                    "_type" : "_doc",
                    "_id" : "1",
                    "_version" : 1,
                    "result" : "created",
                    "_shards" : {
                      "total" : 2,
                      "successful" : 1,
                      "failed" : 0
                    },
                    "_seq_no" : 0,
                    "_primary_term" : 1,
                    "status" : 201
                  }
                },
                {
                  "index" : {
                    "_index" : "my_index",
                    "_type" : "_doc",
                    "_id" : "2",
                    "_version" : 1,
                    "result" : "created",
                    "_shards" : {
                      "total" : 2,
                      "successful" : 1,
                      "failed" : 0
                    },
                    "_seq_no" : 1,
                    "_primary_term" : 1,
                    "status" : 201
                  }
                }
              ]
            }
            ```
            
            建议：bulk 适用于小规模的批量数据导入，如果需要大规模的数据导入，则需要将数据分批导入，以避免单次请求的数据量过大。
            
            - Refresh 参数 - 控制批量操作时刷新索引的时机
                - true：批量操作中的每组操作完成后立即刷新索引，保证每组变更立即可见，保证数据的实时性，但会增加系统开销，降低性能。
                    
                    ```json
                    POST /_bulk?refresh=true
                    { "index" : { "_index" : "my_index", "_id" : "1" } }
                    { "my_field" : "value1" }
                    { "index" : { "_index" : "my_index", "_id" : "2" } }
                    { "my_field" : "value2" }
                    ```
                    
                - false（默认）：整个批量操作完成后刷新索引，所有变更完成后，才对搜索可见，系统开销小，性能好，但是数据实时性差。
                - wait_for：固定时间段触发自动刷新索引（默认1秒），保证批量操作最近一秒变更的数据对搜索可见，平衡IO性能和变更可见性。
                    
                    可以通过 `index.refresh_interval` 设置刷新索引的时间间隔
                    
                    ```json
                    POST /_bulk?refresh=wait_for
                    ```
                    
            
- ElasticSearch 检索
    - 检索方式
        
        ElasticSearch 提供了 `URI Query` 和 `Request Body` 两种方式来实现搜索，它可以通过 `URI Query`查询参数 的方式快速实现数据检索，也可以通过 `Request Body` 请求体 实现更加复杂高级的搜索。
        
        - URI Query
            
            > URI Query 通过在 URL 中直接传递查询参数来实现搜索，适用于简单快速的查询和测试。
            > 
            
            基本结构
            
            ```json
            GET /index/_search?q=query_string
            ```
            
            - 示例
                
                在名为 my_index 的索引中搜索 my_field 字段包含 ”你好” 的文档
                
                ```json
                GET /my_index/_search?q=my_field:你好&sort=&from=0&size=2&timeout=1s
                
                {
                  "took" : 0,
                  "timed_out" : false,
                  "_shards" : {
                    "total" : 1,
                    "successful" : 1,
                    "skipped" : 0,
                    "failed" : 0
                  },
                  "hits" : {
                    "total" : {
                      "value" : 2,
                      "relation" : "eq"
                    },
                    "max_score" : 1.0,
                    "hits" : [
                      {
                        "_index" : "my_index",
                        "_type" : "_doc",
                        "_id" : "1",
                        "_score" : 1.0,
                        "_source" : {
                          "my_field" : "你好，世界"
                        }
                      },
                      {
                        "_index" : "my_index",
                        "_type" : "_doc",
                        "_id" : "2",
                        "_score" : 1.0,
                        "_source" : {
                          "my_field" : "你好，明天"
                        }
                      }
                    ]
                  }
                }
                ```
                
            - 常见查询参数：
                - q：查询字符串参数，用于指定查询条件
                - sort：排序参数，结构为 sort=field:[asc|desc]，可以指定多个字段，如 `sort=field1:asc,field2:desc`
                - from 和 size：分页参数，指定结果集的起始位置和返回的数量。
                - timeout：超时时间参数，指定查询的超时时间。
            
            查询字符串语法：
            
            - 全文查询：
                
                在所有字段上执行全文检索
                
                ```json
                GET /index/_search?q=text
                ```
                
            - 单字段匹配查询：
                
                在指定字段上检索指定值
                
                ```json
                GET /index/_search?q=field:value
                ```
                
            - boolean 操作查询：
                
                用于组合多个查询条件，可以使用 `AND`、`OR`、`NOT` 等布尔操作符
                
                ```json
                GET /index/_search?q=(field1:value1 AND field2:value2)
                ```
                
            - phrase 查询：
                
                用于搜索一个确切的**短语**，要求检索的结果文本中必须按照指定短语的词元顺序连续出现，通常用于精确匹配需要保持词元顺序的情况。
                
                ```json
                GET /index/_search?q="exact phrase"
                ```
                
            - 范围查询：
                
                用于搜索字段值在某个范围内的文档
                
                ```json
                GET /index/_search?q=field:>=20
                GET /index/_search?q=date:[2023-01-01 TO 2023-12-31]
                ```
                
            - 通配符查询：
                
                用于使用通配符（`*` 和 `?`）进行搜索
                
                ```json
                GET /index/_search?q=field:value*
                ```
                
            - 近似度查询：
                
                用于搜索与指定文本相似的文档：允许一定程度的词元置换和距离变动。~ 符号后面的数字表示允许的最大词元移动次数，即“slop”，表示词元可以在指定的 slop 范围内交换位置。
                
                ```json
                GET /index/_search?q=username:jon~2 // 允许两个字符的编辑距离
                ```
                
        - Request Body
            
            > `Request Body` 通过发送复杂的JSON格式的请求体 `QueryDSL` 实现更高级搜索的方法。它适用较复杂或定制化高精度参数查询的场景，如布尔查询、聚合、过滤等。
            > 
            
            基础结构
            
            ```json
            GET /${index_name}/_search
            {
              "query": {
                "查询类型": {
                  "查询属性": "条件值"
                }
              }
            }
            ```
            
            ```json
            GET /my_index/_search
            {
              "query":{
                "match_all": {} // match_all 查询所有文档 match_none 不查询任何文档
                }
              }
            }
            ```

            常见查询类型:
            
            - 精准查询
                
                通过 `term` 或 `terms` 实现单值精准匹配或多值精准匹配，精准查询不会对搜索关键内容进行分词。一般用于keyword文本关键字、数值、日期、布尔类型的字段。
                
                ```json
                // term 单值精准匹配
                GET /my_index/_search
                {
                  "query": {
                    "term": {
                      "my_keyword": {
                        "value": "世界"
                      }
                    }
                  }
                }
                
                // terms 多值精准匹配
                GET /my_index/_search
                {
                  "query": {
                    "terms": {
                      "my_keyword": [
                        "世界",
                        "明天"
                      ]
                    }
                  }
                }
                ```
                
            - 全文检索
                
                > 全文检索对搜索关键内容进行分词，通过倒排索引库检索文档，并根据相关性评分对结果进行排序。
                > 
                - 单字段全文检索 - `match`：
                    
                    用于在指定字段中进行全文检索
                    
                    ```json
                    GET /my_index/_search
                    {
                      "query": {
                        "match": {
                          "my_text": "你好"
                        }
                      },
                      "profile": true // 启用查询分析（profiling）
                    }
                    ```
                    
                - 多字段全文检索 - `multi_match`：
                    
                    用于在多个字段中进行全文检索
                    
                    ```json
                    
                    GET /my_index/_search
                    {
                      "query": {
                        "multi_match": {
                          "query": "世界",
                          "fields": ["my_text", "my_keyword"]
                        }
                      }
                    }
                    ```
                    
                    > 当遇到多字段全文检索的情况时，建议将多个字段 `copy_to` 到一个新的字段中，对新的字段进行单字段全文检索（参与查询的字段越多，查询效率越低）
                    > 
                - 所有字段全文检索
                    
                    > 通过 `query_string` 和 `simple_query_string` 允许在所有字段中进行全文检索。
                    > 
                    
                    ```json
                    GET /my_index/_search
                    {
                      "query": {
                        "query_string": {
                          "query": "你好"
                        }
                      } 
                    }
                    ```
                    
            - boolean 查询
                
                用于组合多个查询条件，常用布尔操作符：`AND`、`OR`、`NOT`
                
                ```json
                GET /my_index/_search
                {
                  "query": {
                    "match": {
                      "my_text": {
                        "query": "你好 世界",
                        "operator": "and"
                      }
                    }
                  }
                }
                ```
                
            - phrase 查询
                
                用于搜索包含特定短语和词元顺序的文档，支持设置 slop 参数允许一定程度的词元置换和距离变动
                
                ```json
                GET /my_index/_search
                {
                  "query": {
                    "match_phrase": {
                      "my_text": {
                        "query": "你好 世界", // 查询按照 “你好 世界” 分词前后顺序的短语
                        "slop": "1"         // 允许 “你好” 与 ”世界“ 中最多出现一个额外的词
                      }
                    }
                  }
                }
                ```
                
            - 范围查询
                
                用于搜索字段值在指定范围内的文档，一般用于数值、日期类型的字段。
                
                ```json
                GET /my_index/_search
                {
                  "query": {
                    "range": {
                      "my_score": {
                        "gte": 60,
                        "lte": 100
                      }
                    }
                  }
                }
                ```
                
            - 正则表达式查询
                
                基于正则表达式的搜索
                
                ```json
                GET /my_index/_search
                {
                  "query": {
                    "regexp": {
                      "my_keyword": "明[天｜日]"
                    }
                  }
                }
                ```
                
    - 检索分析
        
        在 `"profile": true` 参数开启查询分析（profiling），详细了解查询的执行过程以及每个查询的性能表现。
        
        其中包含详细的性能数据，包括：
        
        - 查询的执行时间
        - 每个子句的执行时间
        - 每个阶段的细节（如收集、分析、过滤等）
        - 相关性评分计算的细节
        
        应用场景：深入了解查询执行的内部细节，从而更有效地优化和诊断查询性能
        
        - 性能调优：通过分析查询执行时间，可以识别性能瓶颈，并优化查询结构或索引配置。
        - 故障排查：在查询性能不如预期时，帮助诊断问题根源。
        - 复杂查询分析：在使用复杂查询时，了解各个子句的执行时间和效率。
- ElasticSearch 常见操作汇总
    - **集群操作**
        - **查看集群健康状态**：使用/_cat/health接口获取集群健康信息（绿色绿色、黄色、红色分别表示健康状态
            
            ```bash
            curl -XGET 'http://localhost:9200/_cat/health?v'
            ```
            
        - **查看集群节点信息**：使用/_cat/nodes查看所有节点，或/_cat/master查看当前主节点
            
            ```bash
            curl -XGET 'http://localhost:9200/_cat/nodes?v'
            curl -XGET 'http://localhost:9200/_cat/master?v'
            ```
            
        - **查看索引分片分配**：使用**`/_cat/shards`**查看各索引的主分片与副本分配情况。
            
            ```bash
            curl -XGET 'http://localhost:9200/_cat/shards?v'
            ```
            
        - **查看索引列表**：使用**`/_cat/indices`**列出所有索引及其状态。
            
            ```bash
            curl -XGET 'http://localhost:9200/_cat/indices?v'
            ```
            
        - **查看集群统计**：使用**`/_cluster/stats`**获取集群总体统计信息（文档总数、磁盘使用等）。
            
            ```bash
            curl -XGET 'http://localhost:9200/_cluster/stats?pretty'
            ```
            
        
        ## **索引操作**
        
        - **创建索引（含映射）**：使用PUT请求创建新索引并指定映射配置（7.x 及以上版本无需type）。
            
            ```bash
            curl -XPUT 'http://localhost:9200/product' -H 'Content-Type: application/json' -d '
            {
              "mappings": {
                "properties": {
                  "price":  { "type": "integer" },
                  "name":   { "type": "text" }
                }
              }
            }'
            ```
            
        - **查看索引映射**：使用**`_mapping`**查看索引字段定义。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_mapping?pretty'
            ```
            
        - **获取/更新索引设置**：GET请求可获取索引或集群设置，如**`/_cluster/settings`**或**`/索引/_settings`**；PUT请求更新动态设置（如修改副本数）。
            
            ```bash
            # 查看索引设置
            curl -XGET 'http://localhost:9200/product/_settings?pretty'
            # 修改索引副本数为4
            curl -XPUT 'http://localhost:9200/product/_settings' -H 'Content-Type: application/json' -d '
            {
              "index": { "number_of_replicas": 4 }
            }'
            ```
            
        - **关闭/打开索引**：关闭索引后索引不可用但数据保留，常用于维护；重新开启索引后可继续查询写入。
            
            ```bash
            curl -XPOST 'http://localhost:9200/product/_close'
            curl -XPOST 'http://localhost:9200/product/_open'
            ```
            
        - **删除索引**：使用DELETE请求删除整个索引。
            
            ```bash
            curl -XDELETE 'http://localhost:9200/product'
            ```
            
        
        ## **文档操作**
        
        - **创建/索引文档**：使用PUT或POST请求指定ID写入文档。
            
            ```bash
            curl -XPUT 'http://localhost:9200/product/_doc/1' -H 'Content-Type: application/json' -d '
            {
              "price": 1,
              "name": "富士山苹果"
            }'
            ```
            
        - **获取文档**：通过文档ID读取单个文档。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_doc/1?pretty'
            ```
            
        - **更新文档（部分字段）**：使用**`_update`**接口对已有文档进行增量更新。
            
            ```bash
            curl -XPOST 'http://localhost:9200/product/_update/1' -H 'Content-Type: application/json' -d '
            {
              "doc": { "name": "新名字" }
            }'
            ```
            
        - **删除文档**：通过DELETE请求指定索引和文档ID删除文档。
            
            ```bash
            curl -XDELETE 'http://localhost:9200/product/_doc/1'
            ```
            
        - **批量操作（Bulk）**：一次性执行多条写入、更新或删除操作，提高效率。
            
            ```bash
            curl -XPOST 'http://localhost:9200/product/_bulk' -H 'Content-Type: application/x-ndjson' -d '
            {"index":{"_id":"2"}}
            {"name":"张三","age":12}
            {"index":{"_id":"3"}}
            {"name":"李四"}
            {"delete":{"_id":"4"}}'
            ```
            
        - **根据条件删除**：使用**`_delete_by_query`**接口按查询条件批量删除文档（Elasticsearch 5.x 以后内置）。
            
            ```bash
            curl -XPOST 'http://localhost:9200/product/_delete_by_query' -H 'Content-Type: application/json' -d '
            {
              "query": { "match": { "status": "inactive" } }
            }'
            ```
            
        
        ## **查询操作**
        
        - **查询所有文档**：使用**`match_all`**查询，或简写为查询字符串**`q=*:*`**。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            { "query": { "match_all": {} } }'
            ```
            
        - **全文检索（match查询）**：查询文本字段的匹配，如检索包含“苹果”的文档。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "query": {
                "match": { "name": "苹果" }
              },
              "from": 0, "size": 10
            }'
            ```
            
        - **布尔查询（bool组合）**：将多个条件组合（must、filter、should等）。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "query": {
                "bool": {
                  "must": [
                    { "match": { "name": "苹果" } },
                    { "range": { "price": { "gte": 10, "lte": 20 } } }
                  ]
                }
              }
            }'
            ```
            
        - **分页查询**：通过**`from`**和**`size`**参数控制结果分页，支持深度分页。
            
            ```bash
            # 查询第2页，每页5条
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "query": { "match_all": {} },
              "from": 5, "size": 5
            }'
            ```
            
        - **排序**：通过**`sort`**参数按字段升序或降序排序结果。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "query": { "match_all": {} },
              "sort": { "price": { "order": "desc" } }
            }'
            ```
            
        
        ## **聚合分析**
        
        - **Terms 聚合**：按照字段分组（多桶聚合），统计每个值的文档数。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "size": 0,
              "aggs": {
                "by_genre": {
                  "terms": { "field": "genre.keyword" }
                }
              }
            }'
            ```
            
        - **日期直方图（date_histogram）**：按时间段分桶聚合，如每小时、每天统计量。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "size": 0,
              "aggs": {
                "per_hour": {
                  "date_histogram": {
                    "field": "timestamp",
                    "fixed_interval": "1h"
                  }
                }
              }
            }'
            ```
            
        - **唯一值统计（cardinality）**：统计某字段的不同值数量（去重计数）。
            
            ```bash
            curl -XGET 'http://localhost:9200/product/_search' -H 'Content-Type: application/json' -d '
            {
              "size": 0,
              "aggs": {
                "unique_users": {
                  "cardinality": { "field": "username.keyword" }
                }
              }
            }'
            ```

        ## **批量处理**
        
        - **Bulk 批量操作**：一次提交多条写入、更新、删除指令，格式为NDJSON，每行分别为操作元数据和文档数据。
            
            ```bash
            curl -XPOST 'http://localhost:9200/product/_bulk' -H 'Content-Type: application/x-ndjson' -d '
            {"index":{"_id":"10"}}
            {"name":"张三","age":30}
            {"update":{"_id":"10"}}
            {"doc":{"age":31}}
            {"delete":{"_id":"11"}}'
            ```
            
        - **Reindex**：使用**`/_reindex`**复制或迁移数据到新索引（源索引和目标索引可以不同）。
            
            ```bash
            curl -XPOST 'http://localhost:9200/_reindex' -H 'Content-Type: application/json' -d '
            {
              "source": { "index": "old_index" },
              "dest":   { "index": "new_index" }
            }'
            ```
