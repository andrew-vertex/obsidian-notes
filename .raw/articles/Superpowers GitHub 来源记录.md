## 摘要

Superpowers 是 Jesse Vincent / Prime Radiant 维护的 agentic skills framework 和软件开发方法论。它通过一组可组合 skills，把 brainstorming、worktree、writing-plans、TDD、subagent-driven-development、code review、finishing branch 等流程注入到编码 agent 的日常工作中。
