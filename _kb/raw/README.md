# Global Raw Sources

This folder stores cross-domain source-of-truth material for the vault-level knowledge base.

Rules:
- keep `Clippings/` as the capture inbox
- promote only durable, cross-domain, or high-value sources into `_kb/raw/`
- use domain `_kb/raw/` when a source clearly belongs to one knowledge domain
- do not rewrite source content in place
- add metadata wrappers when provenance needs to be preserved separately
