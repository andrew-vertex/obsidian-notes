# 笔记库知识库架构

这份说明用于约束当前 `/Notes` 仓库中的 LLM 知识库组织方式，避免把整个 vault 都压进一个过大的顶层 `wiki/`。

## Key Takeaways

- 对这个 vault，不推荐把所有正式笔记集中到根目录 `wiki/`。
- 更适合的结构是：根目录使用 `_kb/` 作为全局控制面，各大知识域自己维护 `_kb/`。
- `Tech/`、`Tools/` 这类成熟目录，现有内容本身就可以视为 wiki 层，不需要强制迁移到 `Tech/wiki/` 或 `Tools/wiki/`。
- 顶层控制面文件也应该收敛到 `_kb/raw/`、`_kb/schema/`、`_kb/wiki/`，而不是散落在根目录。
- 只有在某个域需要与旧笔记强隔离时，才额外使用域内 `wiki/` 目录。

## 为什么不推荐单一顶层 wiki

如果整个 vault 只有一套顶层 `raw/ + wiki/ + schema/`，短期看简单，长期会出现几个问题：

- 所有领域的正式笔记都争用同一个 `wiki/`
- 根目录索引会越来越大，导航成本上升
- `Tech`、`Tools`、`Thinking` 这些天然一级分类被绕开
- 领域内 source material 和领域内规则无法就近收纳

## 推荐结构：全局控制面 + 分域知识面

推荐把 root 作为 vault-level control plane，而不是全量知识页容器。

```text
Notes/
  _kb/
    raw/                  # 仅放跨域原始资料或提升后的来源记录
    schema/               # 全局命名规范、frontmatter 规范、知识库架构规则
    wiki/                 # 跨域 hub 页面，不承载所有正式笔记
    log.md                # vault 级维护日志
  Clippings/              # inbox capture 层
  Tech/
    _kb/
      raw/
      schema/
      index.md
      log.md
    Architecture/
    Backend/
    DevOps/
  Tools/
    _kb/
      raw/
      schema/
      index.md
      log.md
    AI/
    Mac/
```

## Tech 和 Tools 的落地方式

### Tech

- `Tech/Architecture/`、`Tech/Backend/`、`Tech/DevOps/` 等现有目录继续作为正式笔记区。
- `Tech/_kb/raw/` 存放该领域的原始来源记录、截图、PDF、剪藏摘要。
- `Tech/_kb/schema/` 存放该领域的命名、目录、页面模板与维护规则。

### Tools

- `Tools/AI/`、`Tools/Mac/` 等现有目录继续作为正式笔记区。
- `Tools/_kb/raw/` 存放安装文档来源、命令摘录、版本核对记录等。
- `Tools/_kb/schema/` 存放文档结构约束，例如目录、Key Takeaways、参考来源的统一要求。

## wiki 是否需要单独目录

默认答案：不需要。

原因：

- 你当前的正式笔记已经按知识域分布在 `Tools/AI/`、`Tools/Mac/` 等目录。
- 强行新增 `Tech/wiki/` 或 `Tools/wiki/` 会引入额外迁移成本。
- 对已有成熟目录，更自然的做法是“现有内容目录即 wiki 层”。

只有在下面情况，才建议给某个域单独加 `wiki/`：

- 该域是新建的，还没有旧笔记包袱
- 你想把“LLM 编译产物”和“人工随手记”彻底隔离
- 该域未来会批量 ingest 大量资料，单独 `wiki/` 更容易控边界

## 索引层级

推荐三层索引：

1. vault 级：`_kb/wiki/index.md`，只做跨域入口
2. domain 级：`Tech/_kb/index.md`、`Tools/_kb/index.md`
3. topic 级：具体笔记页面本身

## 执行规则

- 新资料先进入 `Clippings/` 或其他 inbox
- 再判断属于哪个知识域，决定提升到 root `_kb/raw/` 还是域内 `_kb/raw/`
- 正式笔记优先更新现有领域目录中的页面，而不是无脑新建
- 每次域内 ingest 后，更新域内 `_kb/index.md` 与 `_kb/log.md`
- root `_kb/wiki/` 只保留跨域导航页、方法论页、总览页
