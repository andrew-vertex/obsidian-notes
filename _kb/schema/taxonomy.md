# Global Taxonomy

Define the top-level domains used by this vault-level knowledge base.

## Domains

- `Tech/`: concepts, architectures, back-end systems, agent engineering, DevOps, programming
- `Tools/`: concrete tools, installation guides, configuration, operational usage
- `Projects/`: project-specific notes and implementation records
- `Thinking/`: reading notes, conceptual reflections, meta-level frameworks
- `Life/`: non-technical personal knowledge
- `Work/`: career, resume, work-specific material

## Cross-Domain Categories

- methods
- comparison notes
- workflow design
- source digests
- glossary pages
