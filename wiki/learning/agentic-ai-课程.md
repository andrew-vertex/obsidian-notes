# 吴恩达 Agentic AI 课程笔记

> 学这门课的目的：系统掌握 Agentic 工作流的构建方法——这是 AI 应用开发最核心的工程能力之一。吴恩达强调，真正擅长构建 Agentic 工作流的人和普通开发者之间最大的差异在于**规范化的开发流程**，尤其是错误分析。

## 核心收获

1. **Agentic AI workflow** 是 LLM 应用通过多步骤执行来完成任务，而非一次性 Prompt 输出
2. **自主性是一个光谱**：从完全预定义的确定性步骤（低自主）到 LLM 自主决定步骤序列（高自主）
3. 构建 Agentic 工作流的两个核心能力：**任务分解** + **组件构建**（让每步都能高质量执行）
4. Agentic AI 更适合流程明确、有标准作业程序、以文本资产为主的任务
5. Agentic 工作流可以弥补模型代际差距——好的工作流设计让弱模型超过强模型的一次性输出
6. 低自主性系统在当前企业应用中价值巨大（更可控、更可预测）

## 详细笔记

### 课程介绍

吴恩达指出 "Agentic" 被营销过度使用，但真正有价值且实用的应用在快速增长。他团队构建的许多项目没有 Agentic 工作流完全不可能实现。

### 第一节：Agentic 工作流 vs Prompt

| 方式 | 流程 | 适用场景 |
|------|------|---------|
| Prompt | 一次性输入 → 一次性输出 | 简单问答、翻译 |
| Agentic | 研究 → 草稿 → 修订 → 再研究 → 最终稿 | 研究报告、复杂文档 |

### 第二节：自主性光谱

- **低自主**：预定义步骤，每步由代码控制 → 当前企业主流
- **中自主**：LLM 在预定义步骤间自主选择
- **高自主**：LLM 自主决定步骤序列，动态创建工具 → 研究阶段

### 第三节：三大核心优势

1. **并行化**：多个 LLM 调用同时进行，快于人类顺序处理
2. **模块化**：工具和模型都可以替换，架构灵活
3. **性能弥补**：工作流设计可以让较弱模型超越较强模型的单次输出

### 第四节：四类应用案例

1. 发票处理 — 结构化数据提取 + 规则校验
2. 基础客户订单查询 — 意图识别 + API 调用
3. 高级客户服务 — 多轮对话 + 工具使用 + 知识检索
4. 计算机使用 — 浏览器操作 + 桌面自动化

### 第五节：任务分解

核心方法是观察人类/企业正在做的工作 → 识别离散步骤 → 判断每步能否由 LLM、短代码、API 或工具调用实现。关键判断循环：步骤明确？→ AI 能独立完成？→ 需要多少上下文？→ 与前后步骤如何衔接？
