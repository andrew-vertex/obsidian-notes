# Learn Claude Code 源码阅读路线

## 阅读顺序

1. `README.md`：先理解当前 20 章主线与 legacy track 的差异。
2. `sNN_topic/README.md`：读章节叙事、图示和设计动机。
3. `sNN_topic/code.py`：读最小教学实现，只关注本章新增机制。
4. `agents/*.py`：对照 legacy/测试版本，看可复用结构。
5. `tests/`：看哪些行为被固定为回归测试。
6. `web/src`：最后看可视化站点如何组织内容和交互。
