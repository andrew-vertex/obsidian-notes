# Learn Claude Code 学习总览

## 学习目标

1. 理解 agent = model + harness，而不是提示词编排。
2. 掌握从 agent loop 到工具、权限、记忆、任务系统、多 agent 协作的演进路径。
3. 能用自己的语言复述每章机制，并能改写一个最小实现。

## 推荐节奏

| 阶段 | 章节 | 目标产出 |
|------|------|----------|
| 基础循环 | s01-s04 | 画出最小 loop + tool/hook/permission 流程 |
| 上下文与知识 | s05-s11 | 总结任务、skill、compact、memory、error recovery 的职责边界 |
| 调度与协作 | s12-s18 | 理解任务系统、后台任务、团队协议、worktree 隔离 |
| 集成能力 | s19-s20 | 形成完整 harness 架构图和自己的实现清单 |

## 每章固定输出

- 3 条核心收获
- 1 张流程图或状态图
- 1 段源码阅读摘要
- 1 个可运行实验或改造想法
