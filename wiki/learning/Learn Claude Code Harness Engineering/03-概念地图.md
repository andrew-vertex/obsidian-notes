# Learn Claude Code 概念地图

## 核心命题

> Agent 的能力来自模型；工程师构建的是让模型能观察、行动、记忆和受控执行的 harness。

## 概念分层

| 层级 | 概念 | 对应章节 |
|------|------|----------|
| 执行循环 | agent loop, tool use, hooks | s01-s04 |
| 认知支撑 | todo, subagent, skill, context, memory | s05-s10 |
| 稳定性 | error recovery, permissions, stop condition | s03, s11, s17 |
| 工作流 | task system, background task, cron | s12-s14 |
| 协作与隔离 | agent teams, protocol, worktree | s15-s18 |
| 外部能力 | MCP, comprehensive agent | s19-s20 |
