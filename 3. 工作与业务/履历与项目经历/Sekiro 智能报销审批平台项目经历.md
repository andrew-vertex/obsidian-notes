# sekiro 智能报销审批平台

**项目定位：** 多租户报销审批与特殊医疗作业平台  
**技术栈：** Java、Spring Boot、Spring StateMachine、MyBatis-Plus、MySQL、Redis/Redisson、Elasticsearch、EasyExcel  
**个人角色：** 新项目核心开发，负责审批管理、特殊医疗、组织架构、报表与鉴权等核心模块设计与开发

**项目背景：**  
面向多租户报销审批与特殊医疗业务场景，建设覆盖申请、审核、审批、打款、组织权限和报表导出的平台型系统，满足不同地区、不同业务类型下的差异化流程管理需求。

**项目职责：**  
负责审批流引擎、特殊医疗、组织架构、报表导出、权限控制等核心模块的设计、开发与迭代，推动新项目从业务流程落地到平台能力沉淀。

**项目难点：**  
不同租户、不同业务类型的审批流程差异较大，且涉及多级审核、批次审批、状态回退、操作留痕等复杂场景；同时同一案件在多人协作场景下存在并发审批和状态覆盖风险，需要保证流程一致性与操作可追溯性。

**项目成果：**
1. 负责智能报销审批平台核心链路设计与开发，围绕审批管理、特殊医疗、组织架构、报表管理和鉴权模块构建完整平台能力，支撑多租户报销作业流程线上运行。
2. 基于 Spring StateMachine 设计审批流引擎，并结合策略模式与工厂模式抽象云南/海南、特殊医疗/非特殊医疗等差异化流程，统一管理审核、发起审批、批次审批、打款等状态迁移，降低复杂分支流程的维护成本。
3. 设计案件级并发控制机制，基于 Redisson 实现审核锁能力，记录锁定人、锁状态和锁时间，避免多人同时审批或编辑导致的状态覆盖、重复处理和流程错乱问题。
4. 负责特殊医疗与审批管理模块建设，结合审批快照、操作日志和批次流转机制沉淀完整审核链路，提升审批过程透明度和线上问题排查效率。
5. 负责组织架构模块建设，实现组织树管理、Excel 批量导入导出、身份信息脱敏加密及 ES 同步能力，支撑多层级组织权限管理和基础数据治理。
6. 负责报表与导出能力建设，支持按组织维度输出报销类型、员工类型、年龄结构、病种等统计结果，并通过事件驱动方式实现审批明细、汇总报表及批量导出，提升业务数据交付效率。

**简历短版：**
1. 作为新项目核心开发，负责审批管理、特殊医疗、组织架构、报表与鉴权等核心模块设计与落地，建设面向多租户场景的智能报销审批平台。
2. 基于 Spring StateMachine + 策略/工厂模式抽象差异化审批流，统一管理审核、发起审批、批次审批、打款等状态迁移，解决多地区、多业务类型下流程分支复杂、可维护性差的问题。
3. 基于 Redisson 设计案件级审核锁，约束同一案件在多人协作场景下的并发审批与重复处理，并结合审批快照、操作日志和事件驱动报表导出机制，提升流程一致性、可追溯性和数据交付效率。
