# Domain Maintenance Rules

## Ingest
- add domain-specific sources to _kb/raw/
- update an existing note before creating a near-duplicate
- update _kb/index.md
- append a short entry to _kb/log.md

## Query
- read _kb/index.md first
- save durable answers back into the domain note tree

## Lint
- check for orphan notes
- check for missing source sections
- check for stale or contradictory claims
